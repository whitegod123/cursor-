# 电潜螺杆泵产液量数字计产模型 文献调研报告

**调研目标**：为"电潜螺杆泵（ESPCP）采油系统产液量数字计产模型"研究提供文献支撑。

**论文章节结构约定**（本报告按此组织文献）：

- **第一部分：电潜螺杆泵运行特性模型**（泵本身的客观特性，四个子模型）
  1. 几何与运动学模型 —— 理论排量、泵因数、腔室容积，一切模型的基础
  2. 流量-漏失特性模型 —— 理论流量、漏失量与实际产液量的关系
  3. 功率-扭矩特性模型 —— 电参数、轴功率、泵扭矩与负载的关系
  4. 容积效率修正模型 —— 压差、温度、黏度、磨损等因素对产液量的综合修正
- **第二部分：电潜螺杆泵产液量数字计产模型建立**（方法实现，单独成章）
  参数标定、误差评价、模型验证、（可选）机器学习修正

**适用场景**：高含水油田电潜螺杆泵井，具备井下压力、温度、电参数实时数据
及地面单量测试数据。

## 五、文献空白与本研究定位

1. PCP 漏失/容积效率机理模型成熟（C1、E1-E3），但多面向**泵设计选型**，
   面向**单井连续计产**的应用研究少；
2. 直接以"电潜螺杆泵产液量计产"为题的期刊论文缺乏（仅学位论文 C9、C10
   与专利 P1），**本研究填补该空白**；
3. 高含水工况下的 PCP 计产（低黏度、大漏失占比）鲜有专门讨论，
   本研究的"水黏度解析式 + 湍流指数标定"处理是针对性贡献；
4. 机理模型与电参数校核的融合（数据质量闭环）在现有文献中未见系统化表述。
